# WaxwingCompanion — Xcode Project Setup

This guide will help you create an Xcode project that references the source files in place, so you don't need to copy them every time.

## Quick Setup (One-time, ~5 minutes)

### 1. Create New Xcode Project

1. Open Xcode
2. **File → New → Project** (or ⌘N)
3. Select **iOS → App** → Next
4. Fill in:
   - **Product Name:** `WaxwingCompanion`
   - **Team:** Leave empty for now (configure later)
   - **Organization Identifier:** `com.waxwing`
   - **Interface:** SwiftUI
   - **Language:** Swift
5. **Important:** Save the project **outside** the repo (e.g., your Desktop or Documents)
   - This way the `.xcodeproj` file won't be accidentally committed

### 2. Add Existing Source Files

Instead of letting Xcode create new files, we'll add the existing ones:

1. In Xcode's Project Navigator (left sidebar), delete the placeholder files:
   - `ContentView.swift` (delete → Move to Trash)
   - `WaxwingCompanionApp.swift` (delete → Move to Trash)

2. **File → Add Files to "WaxwingCompanion"**
3. Navigate to: `/Users/billy/Projects/Waxwing/ios/WaxwingCompanion/WaxwingCompanion/`
4. Select **all** the Swift files and folders
5. **Important options:**
   - ✅ **Copy items if needed** — UNCHECK this (keep files in place)
   - ✅ **Create groups** — Select this
   - ✅ Add to target: `WaxwingCompanion` — Make sure this is checked
6. Click **Add**

### 3. Add Info.plist (if not present)

If Xcode didn't create an Info.plist automatically:

1. Right-click on the `WaxwingCompanion` folder in Project Navigator
2. **New File…** → **iOS → Resource → Property List**
3. Name it `Info.plist`
4. Add these keys:

| Key | Type | Value |
|-----|------|-------|
| `NSBluetoothAlwaysUsageDescription` | String | `Waxwing scans for and connects to nearby Waxwing mesh nodes over Bluetooth LE.` |
| `NSBluetoothPeripheralUsageDescription` | String | `Waxwing uses Bluetooth to communicate with nearby mesh nodes.` |
| `NSCameraUsageDescription` | String | `Waxwing uses the camera to capture photos for uploading to your Waxwing mesh node.` |
| `NSLocationWhenInUseUsageDescription` | String | `Your location is used to geo-tag images you share with the Waxwing mesh.` |
| `NSPhotoLibraryUsageDescription` | String | `Waxwing needs photo library access to select photos for upload.` |
| `NSPhotoLibraryAddUsageDescription` | String | `Waxwing saves processed images to your photo library.` |

Or use the pre-created Info.plist at `ios/WaxwingCompanion/Info.plist` by adding it via "Add Files to…"

### 4. Configure Signing

1. Select the **WaxwingCompanion** project (blue icon) in the navigator
2. Select the **WaxwingCompanion** target
3. Go to the **Signing & Capabilities** tab
4. ✅ Check **"Automatically manage signing"**
5. Select your **Personal Team** from the Team dropdown
6. The Bundle Identifier should be: `com.waxwing.WaxwingCompanion`

### 5. Build and Run

1. Connect your iPhone via USB (first time only)
2. On your iPhone: **Settings → Privacy & Security → Developer Mode** → Turn ON → Restart
3. In Xcode, select your iPhone from the device dropdown
4. Press **⌘R** to build and run

---

## Benefits of This Setup

- **No copying:** Source files stay in the repo
- **Auto-sync:** Any changes to `.swift` files are picked up immediately
- **Git-friendly:** The Xcode project can be on your Desktop, not in the repo
- **Easy iteration:** Make changes in your favorite editor, rebuild in Xcode

---

## Troubleshooting

**"Could not find module" errors**
- Make sure all source files are added to the target (file inspector on the right)

**Bluetooth permission crash**
- Verify Info.plist has `NSBluetoothAlwaysUsageDescription`

**Untrusted developer**
- Settings → General → VPN & Device Management → Trust your developer
